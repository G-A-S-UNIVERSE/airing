# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Reporting a Vulnerability

Please report security vulnerabilities by opening a **private** GitHub Security
Advisory (Security -> Advisories -> New draft security advisory) rather than a
public issue.

We aim to respond within 72 hours and provide a fix within 14 days for critical
issues.

Do not disclose vulnerability details publicly until a fix has been released.

## Scope

This project is a reference implementation that runs against mocked data. Reports
about the reference implementation itself are in scope, as are reports of
credential or customer-data exposure in the public repository.
